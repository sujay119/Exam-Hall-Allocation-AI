# 3. CORE AI ALGORITHM

Implement the exam hall allocation as a **Constraint Satisfaction Problem**.

Define:

### Variables

Each student is a variable.

Example:

```text
S001
S002
S003
...
```

### Domains

Each student's domain contains possible seats.

Example:

```text
Room A - Row 1 - Seat 1
Room A - Row 1 - Seat 2
Room A - Row 1 - Seat 3
...
```

### Constraints

Implement at least these constraints:

1. A seat can contain only one student.
2. A student can occupy only one seat.
3. Room capacity cannot be exceeded.
4. Students from the same class/section should preferably not sit adjacent to each other.
5. Students taking the same subject should preferably not sit adjacent to each other.
6. Restricted/special students can be assigned only to suitable seats if such information is provided.
7. All mandatory constraints must be satisfied.
8. The algorithm should minimize seating conflicts.

# 4. CSP BACKTRACKING

Implement a real recursive backtracking solver.

Use:

```text
backtracking_search()
```

```text
select_unassigned_variable()
order_domain_values()

```

The solver should return:

```python
{
    "success": True,
    "assignment": {...},
    "conflicts": [],
    "statistics": {...}
}
```

If no valid arrangement exists, return a useful explanation instead of crashing.

---

# 5. HEURISTICS

Implement AI heuristics.

At minimum implement:

### MRV

Minimum Remaining Values.

Choose the student with the smallest number of valid remaining seats.

### Degree Heuristic

If two students have the same MRV value, select the student involved in the largest number of constraints.

### Least Constraining Value

Prefer the seat that restricts the fewest options for other students.

Clearly comment the code explaining these AI concepts.

---

# 6. CONSTRAINT PROPAGATION

Implement forward checking.

Whenever a student is assigned:

```text
Student → Seat
```

remove conflicting seats from the domains of other students.

If another student's domain becomes empty:

```text
Backtrack
```

This should be a genuine implementation rather than a placeholder function.

---

# 7. LOCAL SEARCH

Also implement a simple optional local-search optimization stage.

For example:

```text
Initial valid allocation
        ↓
Calculate conflict score
        ↓
Swap students
        ↓
Calculate new conflict score
        ↓
Keep improvement
        ↓
Repeat
```

Implement either:

- Hill Climbing

or

- Min-Conflicts

Prefer **Min-Conflicts** because it is highly relevant to CSP.

Keep this implementation in:

```text
ai/heuristics.py
```
